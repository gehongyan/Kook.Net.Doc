Remarks

除 Id 外，所有属性都是可空的：服务端不保证每次都下发全部字段，null 表示服务端没有给出该字段。 成员之后的状态变化（例如麦克风静音）不会更新此快照，请通过 IWebRtcAudioClient 上对应的事件获知。
